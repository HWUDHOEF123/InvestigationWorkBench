# M0 技术验证摘要

两套工作树在 2026 年 11 月 21 日使用 Graphiti 0.31.2、Neo4j 2026.10.2、DeepSeek `deepseek-flash` 和百炼 `qwen3.7-text-embedding` 完成了技术试验。以下是 v1.5.2 采用的结论与仍须验收的行为。

| 项目 | 试验结果及开发约定 |
| :--- | :--- |
| 结构化抽取 | 四档思考强度均产出了可解析的 JSON，独立试验的 `medium` 档出现过一次解析失败并在重试后恢复。类型化属性可能带上模型回显的外层对象，直接写入会导致 Neo4j 回滚。适配器须解包并严格校验字段，以 Episode 成功提交作为验证标准。 |
| 中文输出与别名 | 两套试验均得到中文事实。双语名称可能生成重复节点，逐块传入命名规则和案件已知别名。 |
| 视觉转写 | 试验中的中文截图转写成功。批量请求遇到无效图片会整单被拒绝，上传后应先校验，收到可定位到单张图片的错误时剔除对应图片并重发。 |
| 向量与全文检索 | 向量模型的原生输出为 1024 维。两套小样本试验均未观察到 `cjk` 提升中文召回，沿用默认分析器。跨语言实体解析仍需已知别名和手工合并兜底。 |
| 矛盾写回 | 脚本化模型验证了 `invalidated_by` 捕获、写回及后续读取。真实模型仍可能选错矛盾候选。两条事实起点相同时，Graphiti 可能不执行失效，消歧合并也可能丢弃明确写出的结束时间。P3 按唯一匹配和信源等级处理陈述终点。 |
| 案件隔离 | 使用明确的 `group_id` 时，两案件保持隔离。适配器拒绝缺失或空范围，查询按案件精确过滤。 |
| 故障续传 | 两套试验都发现，已提交的 Episode 无法完整还原因果映射和写入前的边时间。Graphiti 写入前先暂存捕获结果，重启时仅在 Episode UUID 匹配时重放策略。 |
| 时间归一化 | 场景试跑中，只到日期的生效时间被读成 UTC 午夜，比上海本地午夜晚八小时。适配器需按案件时区归一化，验收检查结束前一分钟和结束时刻。 |
| 遥测 | 两套试验均在独立进程中验证关闭遥测。继续在 pytest 之外验证，因为 pytest 会自动关闭 Graphiti 遥测。 |

两套工作树冻结的样例日期和来源版本不同。v1.5.2 采用 `D = 2026-12-01`，A5 的生效时刻为 `2026-12-15T00:00:00+08:00`。M0 表明方案具备技术可行性，真实模型下的矛盾识别及 A5 行为仍按 M1 的验收标准验证。
